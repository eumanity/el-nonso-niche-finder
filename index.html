How the score works
Score (0–100) = 40% demand (median views per day) + 25% outlier rate (videos with 2× more views than the channel has subscribers) + 20% small-channel share (results from channels under 50k subs) + 15% new-channel share (channels under 12 months old). High score = people are watching and small or new channels are getting those views.

API keys

Keys are saved only in this browser on this computer. They go straight to Google and nowhere else.

Getting your keys (5 minutes)

YouTube Data API v3
  1. Go to console.cloud.google.com and create (or pick) a project.
  2. Open APIs & Services → Library, search for YouTube Data API v3, and click Enable.
  3. Open APIs & Services → Credentials → Create credentials → API key.
  4. Edit the key and under API restrictions choose Restrict key → YouTube Data API v3. Leave Application restrictions on None: this file runs from your computer, so a "Websites" restriction will block it.
Gemini
  1. Go to aistudio.google.com/apikey and click Create API key. The free tier is enough to start.
